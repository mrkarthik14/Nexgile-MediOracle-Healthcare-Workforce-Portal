# Analytics App

## Responsibility Boundary
The `analytics` app aggregates cross-ward workforce KPIs for hospital executives and agency leadership:
- **Real-Time Dashboards:** Fill rate trajectories, average time to fill (hours), cancellation rates, and compliance health.
- **Budget vs. Actual Spend:** Department-by-department financial tracking.
- **Invoice Aging Analysis:** Accounts receivable and payable delinquency monitoring.
